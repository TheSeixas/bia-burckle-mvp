BDK-BIA-BURCKLE-SITE-DEMO-CORRIGIDO
Correção manual solicitada pelo operador sobre a demo gerada pelo BDK.

Correções:
1. HOME: removida a hero textual gigante "Encontre sua peça."; topo agora é carrossel visual com navegação/CTAs.
2. CATÁLOGOS: paginação real no cliente (anterior, páginas, próxima) para biquínis, pronta-entrega e maiôs.
3. PDP: foto e interface foram separadas estruturalmente. A área de imagem não contém controles de compra; controles funcionais de cor, tamanho, preferência e quantidade ficam fora da foto.
4. COR: seleção por botões de cor; compra exige cor e tamanho.
5. QUANTIDADE: stepper +/- funcional e persistência no carrinho.
6. CARRINHO: persiste no localStorage e mostra cor/tamanho/quantidade.
7. ROTAS: links locais verificados; nenhuma referência HTML local quebrada encontrada.
8. RESPONSIVIDADE: layout mobile/desktop e reduced-motion preservados.

Observação:
As imagens de produto de origem da demo do BDK eram capturas do site oficial via image.thum.io. O CSS do PDP foi alterado para apresentar a região visual do produto separada dos controles. Para uma entrega comercial definitiva, substituir as referências de captura por arquivos/imagens oficiais de produto licenciadas é recomendado.
